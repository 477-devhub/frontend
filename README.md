# 477 Frontend

작업 범위: **HACKATHON-DAY**, 2026-10-09.

## 실행 및 검증

- `npm run dev`: 로컬 화면
- `npm test`: 로컬 provider의 계약·상태 변경 테스트
- `npm run build`: 타입 검사 및 배포용 빌드

## 연동 준비

`src/contracts/api.ts`에 API 1.2 타입을 정의하고 `src/fixtures/backend-api-v1.2.json`에 백엔드 예시의 사본을 보관합니다. `src/console/localProvider.ts`는 네트워크를 사용하지 않는 상태 공급자이며 `useConsole.ts`가 화면 상태와 작업 진행을 관리합니다. 실제 연동은 이후 별도 작업으로 진행합니다.

사건 상세는 ID로 선택하며 서버 형식의 순위와 점수를 표시합니다. Risk와 Confidence를 분리하고 null 위험도는 미측정으로 표시합니다. 로컬 ACK·검토·인계·출동 의사 기록 및 제외 알림 복원을 제공하며 동일 요청 키의 중복 변경을 방지합니다. 오류·로딩·오래된 데이터 표시 예시는 상단 선택기로 확인합니다.

이미지는 기존 번들 이미지의 합성 미리보기입니다. 실제 클립·근거·타임라인이 없는 경우 빈 상태를 표시합니다. 데모 점수는 측정된 성능이 아니며 latency·비용·정확도 개선 수치를 제시하지 않습니다. 사전 제작 자산과 API fixture의 출처는 기존 저장소와 백엔드 예시이며 이번 변경을 행사 당일 새로 촬영하거나 측정한 자료로 간주하지 않습니다.
